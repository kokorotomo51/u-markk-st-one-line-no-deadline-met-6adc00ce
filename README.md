# One Line, No Deadline Met

An entry for the [One Line, No Deadline Met](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce) bounty on make.fun.

The entry is a single original one-line joke giving an excuse for a missed deadline. Its setup treats the deadline like a software update that can be postponed; the middle keeps hitting the snooze button; the punchline turns the tables, with tomorrow itself taking legal action against the procrastinator.

Run it with Node 22:

```sh
node main.ts
```
